About these numbers & data sources

Reported activity is the sum of the exported app and website rows. It is not unique elapsed screen time: websites may overlap browser time, devices may be used together, and identical names may represent different entries. Durations are rounded by Shortcuts.

Only the latest completed-day export per date and device scope is selected. If none exists, the latest partial snapshot is shown. Repeated snapshots are never added together. Completed-day queries can still change as Apple syncs data.
