About these numbers & data sources

Website rows from Shortcut exports are shown as detail, excluded from totals when a browser is present. Their browser association is unknown. Exporter app sessions use a separate per-device scope and are never added to Shortcut totals. Overlapping intervals of the same app on one device are merged. Different apps or devices may still overlap. Calendar events never add to screen time.

Only the latest completed-day export per date and device scope is selected. If none exists, the latest partial snapshot is shown. Repeated snapshots are never added together. Completed-day queries can still change as Apple syncs data.
